# Planet Orbit Simulation

A Python simulation of a planet going around the Sun, using Newton's law of gravity and small time steps.

How it works: at each step the Sun's pull changes the planet's speed, and the speed changes its position. The code draws the path of the planet.

What I tried: I changed the starting speed (vy). With vy = 1.0 the orbit is a circle. With 0.8 and 1.2 it is an ellipse. With 1.5 the planet flies far away from the Sun.

How to run: open orbit.py in Google Colab and run it.

What I learned: I learned how to use Python loops and Newton's law of gravity to simulate a planet's orbit, and how the starting speed changes the path.
